Never run shell commands through `child_process`, `Bun.spawn`, or a helper that wraps them, even when you need the output. Start the command with `const h = bash(cmd)`; in a later `javascript` call, collect `const r = await h` (this returns instantly if the command already finished) and use `r.output` and `r.exitCode`. Only commands that finish in under a second may be awaited inline.
